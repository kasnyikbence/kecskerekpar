#Kecskerékpár - Kerékpárbolt 

Egy modern webalkalmazás a **Kecskerékpár** üzlet számára, amely **Angular** keretrendszerben készül. Jelenleg a projekt korai fázisban van: a **főoldal** készült el, amely bemutatja az üzlet arculatát és az új design-t.
